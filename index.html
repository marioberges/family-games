Offline-first web apps, built to live on the home screen.

Hoist

Flag recognition drill

197 country flags, drilled with spaced repetition. Answer from four names, or find the country on a world map — the map zooms to whichever slice of the world you pick, from one region up to all 197. Progress is saved between sessions, and once the flag art is downloaded it all runs in airplane mode.

Lattice

Times tables drill

The times tables to 12, drilled with spaced repetition. Answer from four numbers or type it on a keypad, one table at a time or all 78 facts at once — and see 6 × 7 drawn as six rows of seven dots, which is what it actually means. It times how long recall takes and never shows a clock: all that does is decide when a fact is finished with. Nothing to download, so it works offline from the first launch.

Putting a game on the iPad

  1. Open this page in Safari — Chrome and Firefox on iOS cannot install web apps.
  2. Tap the game, then Share → Add to Home Screen → Add.
  3. Launch it from the home screen. It opens full screen, no browser chrome.
  4. Do any one-time downloads while you still have signal. Hoist needs Save all flags; Lattice needs nothing.
